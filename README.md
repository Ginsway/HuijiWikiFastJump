# HuijiWikiFastJump
灰机Wiki模板快速跳转油猴脚本，IDE式一键打开MediaWiki模板页面，高效查阅模板用法

## 功能介绍
在灰机Wiki编辑页面按下 `Ctrl + 鼠标左键` 点击页面内模板名称，会直接新开标签页跳转至对应MediaWiki模板页面，无需手动复制、搜索模板名，像IDE跳转定义一样便捷，大幅提升编写Wiki时查阅模板参数、用法的效率。

## 安装步骤
### 1. 安装油猴脚本管理器
主流浏览器任选其一安装插件：
- Chrome / Edge：[Tampermonkey](https://chrome.google.com/webstore/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)
- Firefox：[Tampermonkey](https://addons.mozilla.org/firefox/addon/tampermonkey/)
- Safari：[Tampermonkey for Safari](https://apps.apple.com/app/tampermonkey/id1482490899)

> 提示：无法访问 google webstore 的，可以在Tampermonkey的官网<https://www.tampermonkey.net/index.php?browser=chrome>下载

### 2. 一键安装本脚本
点击下方链接，Tampermonkey会自动弹出安装窗口，点击「安装」即可：
